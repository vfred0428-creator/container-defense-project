# Character and menu artwork

Generated using the built-in image generation tool for the reference-directed visual upgrade. The original user screenshots guided the character identities, toy-like materials, navy/gold UI palette and warm container courtyard. These PNGs are portrait illustrations and a menu background; the playable residents remain procedural 3D models with improved faces, outfits and props.

Assets are in `Assets/Resources/Art/`. The game uses the original PNGs without destructive image editing. Skin portraits were generated as edits of their character's default portrait.

Premium detailed 3D vinyl toy render, huge glossy chocolate-brown expressive eyes with iris highlights, small nose, soft pink cheeks, warm friendly smile. Very large rounded head about 55 percent of total height, compact cuddly body, short limbs, richly modeled hair clumps, plush fabric textures, stitched seams, polished toy surfaces. Full body standing neutral friendly pose, facing camera with slight three-quarter angle, both feet visible, centered with generous clear padding. Soft warm studio key light from upper left, gentle cool rim, balanced bright readable material colors. ACTUAL TRANSPARENT BACKGROUND with clean alpha, no environment, no ground plane, no cast shadow outside silhouette, no labels, no letters, no text, no watermark, no panels, no duplicate figures. This is production character art, not a UI mockup or a flat vector illustration.

Use case: stylized-concept. Asset type: a 16:9 landscape main-menu background painting for Container Defense, an original premium cute chibi collectible game. No UI or characters in foreground. An enchanting industrial shipping container courtyard at sunset with exactly six single-story colorful shipping container homes in a broad horizontal row, blue, rose pink, golden yellow, teal, lavender, coral. Each has a warm glowing door, inviting potted plants and tiny wooden steps; stacked cargo containers and cranes in the sides and background. Warm strings of amber bulbs across sky, cozy industrial lamps, wet cobbled courtyard with golden reflected bokeh. A huge billowing purple charcoal storm-cloud monster with menacing glowing coral eyes and mischievous jagged smile rises far behind the houses in a dramatic pink orange lavender dusk sky. Premium detailed stylized 3D animated film rendering, toy diorama materials, inviting warm light contrasting looming cool smoke. Camera low eye-level wide composition, open courtyard foreground in lower third, six homes across middle, cloud at upper center. Decorative backdrop for UI so no text whatsoever, no logos, no names, no game interface, no overlays, no foreground people, no watermark. Render widescreen 16:9.
